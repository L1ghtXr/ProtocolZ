# Security Policy

ProtocolZ is pre-alpha and has **not** been independently audited or certified.

## Reporting a vulnerability
Do not open a public issue. Use GitHub's private "Report a vulnerability" advisory on this
repository (enable it before release) or the contact the maintainers publish here:
`TODO: security contact — founder to fill in before public release`.
Please include version, reproduction steps, and impact. Expect an acknowledgement; no SLA is promised yet.

## Scope and acceptable use
ProtocolZ is for defending infrastructure you own or are authorized to protect. Contributions that add
offensive capability (botnets, retaliation, unauthorized interception, uncontrolled packet generation)
will be rejected.
