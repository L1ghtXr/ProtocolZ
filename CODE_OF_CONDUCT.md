# Code of Conduct

We want ProtocolZ to be a place where people can do careful security engineering together.

- Be respectful and assume good faith; critique code and ideas, not people.
- No harassment, discrimination, doxxing or personal attacks.
- Security work here is **defensive only**. Proposals or contributions that add offensive capability (botnets, retaliation, unauthorized access, uncontrolled traffic generation) are out of scope and will be declined.
- Report vulnerabilities privately (SECURITY.md), not in public issues.

This is a short project-specific code written for this repository, not the Contributor Covenant text.
